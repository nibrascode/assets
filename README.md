# nibrascode assets

Heavy static files for nibrascode.com, served by GitHub Pages (https://assets.nibrascode.com):

- `ffmpeg/` — ffmpeg.wasm core (@ffmpeg/core 0.12, LGPL/GPL, see upstream) for the video tools
- `pdf-assets/ocr/` — Tesseract.js worker/core + traineddata (Apache-2.0)
- `pdf-assets/fonts/` — DejaVu / Noto Naskh Arabic fonts (see licenses)

See `pdf-assets/LICENSES.txt`.
